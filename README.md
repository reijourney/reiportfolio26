# Portofolio Muhammad Reihan Prasetya — 2026

Website portofolio responsif dengan mode terang dan gelap.

## Menjalankan website

Buka `index.html` langsung di browser, atau unggah seluruh folder ke GitHub Pages, Netlify, Vercel, maupun hosting biasa.

## Struktur file

- `index.html` — struktur halaman dan konten utama.
- `style.css` — tampilan khusus, animasi, responsivitas, serta warna mode terang/gelap.
- `tailwind.css` — utility CSS lokal yang sudah dikompilasi, sehingga layout tidak bergantung pada Tailwind CDN.
- `script.js` — data pengalaman/proyek, galeri, menu mobile, animasi scroll, dan pengaturan tema.
- `img/` — seluruh foto, thumbnail proyek, sertifikat, dan dokumentasi.

Pilihan tema disimpan di `localStorage` dengan key `portfolio-theme`, sehingga tema terakhir tetap digunakan saat pengunjung membuka website kembali.

Seluruh gambar raster telah dioptimalkan ke format WebP untuk mempercepat waktu muat tanpa mengurangi ketajaman tampilan secara signifikan.
